## 🔄 OPAR: The Transversal Operator

OPAR is not a layer. OPAR is the **dynamic grammar** that animates the system.

```
    ┌──────────────────────────────────────────────────────────┐
    │                                                          │
    │   OBSERVE ──────► PROCESS ──────► ACT ──────► REFLECT   │
    │      │               │             │             │       │
    │      ▼               ▼             ▼             ▼       │
    │   ┌─────┐        ┌─────┐       ┌─────┐       ┌─────┐    │
    │   │ L1  │        │ L2  │       │ L3  │       │ L1  │    │
    │   │ L2  │        │ L3  │       │ L4  │       │ L3  │    │
    │   │     │        │ L4  │       │     │       │     │    │
    │   │PEM◄─┼────────┼─────┼───────┼─────┼───────┼──►PEM    │
    │   └─────┘        └─────┘       └─────┘       └─────┘    │
    │                                                          │
    │   PEM spans the entire loop: failure memory persists     │
    │                                                          │
    └──────────────────────────────────────────────────────────┘
```

| OPAR Phase | What happens | LifeOS Layers touched | LLAT relevance |
|------------|--------------|----------------------|----------------|
| **Observe** | Perceive environment | L0-L2 (Perception, Memory) | Trace capture |
| **Process** | Reason, interpret | L3-L4 (Interpretation, Reasoning) | Semantic structure |
| **Act** | Decide, execute | L5-L6 (Decision, Action) | Action trace |
| **Reflect** | Evaluate, learn | L7-L8 (Reflection, Meta) | Error → PEM |
